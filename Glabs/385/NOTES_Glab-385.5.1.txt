THE ONE THING WORTH REMEMBERING FROM THIS LAB
---------------------------------------------
The lab tells you to attach the source timezone like this:

    dt = dt.replace(tzinfo=from_tz)

That is what the submission uses, and it is correct for this lab's example.
But it only works because the source zone here is UTC.

Why: pytz's UTC is a single fixed object with one permanent offset, so
replace() grabs the right thing. Most other zones instead carry a whole table
of historical offsets, and replace() silently grabs the FIRST entry in that
table, which is Local Mean Time from the 1800s.

So if you convert FROM "America/New_York" instead of UTC, replace() gives you
an offset of -04:56 instead of -05:00. Four minutes off, and it fails silently.

The correct general-purpose version is:

    dt = from_tz.localize(dt)

localize() picks the offset that was actually in effect on that date,
including daylight saving time. Use replace() only when the source is UTC.

Do NOT change the submission to localize() -- the lab's own instructions and
its explanation cell both specify replace(), so the graded file should match.
